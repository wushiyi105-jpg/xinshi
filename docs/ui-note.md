# UI 说明：信使

- **谁在什么时刻打开**：给管合作邮件的人。
- **首屏任务句**：谁还在等我回邮件。
- **主操作**：按「选邮件线程 → 找承诺与等待 → 起回复草稿」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：分拣信台；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：分拣信台。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给管合作邮件的人：导入选中的邮件线程，识别对方问了什么、我承诺了什么、谁在等谁，生成保留原事实的回复草稿。
